# Documentation Style Guide

This document gives the writing rules for all Vigil documentation. The rules come from ASD-STE100 Simplified Technical English, Issue 9 (January 2025). Write all Vigil documentation in this style.

The purpose of these rules is to make the text clear, simple, and unambiguous. Readers throughout the world can understand text that obeys these rules.

These rules are a summary of the full standard. For the full rules, refer to the ASD-STE100 Simplified Technical English specification, Issue 9.

## Purpose of this guide

Write technical text so that readers understand it the first time that they read it. Use short sentences. Use one meaning for each word. Use the same term for the same item in all the text.

## Words

Use simple and common words. Do not use:

- Jargon words.
- Slang words.
- Regional words.
- Words that are not necessary.

Use consistent terminology. Use the same word for the same item in the full document. Do not use different words for the same item.

Use nouns for objects and verbs for actions. Do not use a noun as a verb or a verb as a noun.

## Sentences

Use short sentences. For instructions and procedures, use a maximum of 20 words in each sentence. For descriptions, use a maximum of 25 words in each sentence.

Write one instruction in each sentence. Do this unless two or more actions occur at the same time.

Do not omit words. Do not use contractions (for example, "don't" and "isn't"). Write all the words in full.

Use the active voice. Do not use the passive voice. In a descriptive text, you can use the passive voice only when the agent (the person or thing that does the action) is unknown.

Use the active voice for procedures. The reader must know who does the action.

## Verbs

Use these verb forms:

- The infinitive form.
- The imperative form (command form).
- The simple present tense.
- The simple past tense.
- The simple future tense.
- The past participle form (as an adjective).

Do not use auxiliary verbs to make complex verb constructions. Do not use the present perfect tense or the past perfect tense.

In procedures, write instructions in the imperative (command) form. For example, "Set the switch to ON."

Do not use the "-ing" form of a verb, except as a technical noun or as a modifier in a technical noun.

## Articles

Use an article (the, a, an) or a demonstrative adjective (this, these) before a noun when it is appropriate. Do not omit articles to make the text shorter.

Do not use an article before a general statement or a concept. For example, "Solvents can cause damage to paint."

## Punctuation

Use standard English punctuation. Do not use the semicolon (;). Write two sentences instead.

Use the colon (:) to introduce a vertical list. In a vertical list, the colon shows the end of a sentence.

Use hyphens (-) to connect words that are directly related. For example, "soap-and-water solution."

Use parentheses ( ) to:

- Make references to illustrations or text.
- Include letters or numbers that identify items.
- Identify work steps in a procedure.
- Include abbreviations.
- Give the singular and plural forms of a noun at the same time.
- Explain words or a part of a sentence.
- Include an alternative.

## Word count

Count these as one word each:

- Numbers.
- Numbers together with units of measurement (for example, 10 mA).
- Abbreviations.
- Alphanumeric identifiers.
- Quoted text.
- Titles, headings, and text on labels.
- Proper nouns.
- Text in parentheses.
- Hyphenated words.

## Procedures

A procedure is a sequence of work steps. Write each work step as one instruction.

Use numbers or letters to show the sequence of the work steps.

Use the imperative form for instructions. For example, "Remove the four bolts."

When the reader must know a condition first, write the condition first. Then write a comma. Then write the instruction. For example, "When the surface is dry, apply the primer."

Use notes only to give information, not instructions. A note must not give limits, tolerances, or results of a work step.

## Descriptive text

Descriptive text gives information, not instructions. Do not use the imperative form in descriptive text.

Give information gradually. Give one topic in each sentence where possible.

Use paragraphs to show related information. Each paragraph has only one topic. No paragraph has more than six sentences.

Use key words and key phrases to give the text a logical structure. Use the same key words throughout the text.

## Safety instructions

Use safety instructions to tell readers that a task can be dangerous or cause damage.

- Use a warning when there is a risk of injury or death.
- Use a caution when there is a risk of damage to objects.
- Use a warning when there are the two levels of risk together.

Start a safety instruction with a clear and accurate command or condition. Then give an explanation that shows the risk or the possible result.

## Checklist for writers

Before you finish a document, do this check:

- Does each sentence have a maximum of 20 words (procedures) or 25 words (descriptions)?
- Does each sentence have one instruction or one idea?
- Does each sentence use the active voice?
- Does each procedure use the imperative form?
- Does each noun have the same term in the full document?
- Does the text use the same key words for the same ideas?
- Does the text avoid the semicolon, contractions, jargon, and the "-ing" form?
- Does each paragraph have one topic and not more than six sentences?
- Does each abbreviation appear in full the first time that it occurs?
